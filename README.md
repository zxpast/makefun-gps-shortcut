# The GPS Swears It Was a Shortcut

The GPS's own excuse for sending the driver down the wrong road: that cul-de-sac wasn't a mistake, it was the map's wedding venue — and the bride has already sent it a thank-you card.

`main.ts` (Node 22+, stdlib only) writes the single line to
`/output/entry.txt`, with a self-check that it is one non-blank line of
1–200 characters. Run it with `node main.ts`.
